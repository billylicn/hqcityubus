# 班次数据维护

网站只把这里的文件作为班次数据源；构建时会自动生成前端使用的 JSON。

## 更新时刻表

1. 编辑 `routes/城市大学到横琴.txt` 或 `routes/横琴到城市大学.txt`。
2. 每条线路用一行标题开始，例如：`1. A5线-澳琴午下班`。
3. 站点格式为 `HH:MM 站点名称`。
4. 每条线路必须且只能标注一个 `【上车】` 和一个 `【下车】`，并且上车站要早于下车站。
5. 运行 `npm run data:check` 验证，运行 `npm run data:generate` 更新生成文件。

示例：

```text
1. 示例线
08:00 起点
08:15 澳门新濠锋酒店【上车】
08:45 横琴口岸【下车】
```

跨午夜班次可以直接把午夜后的时间写成 `00:xx`，生成器会自动识别为次日。

## 修改运营日

`config.json` 定义数据文件、方向以及默认运营日。`serviceDays` 使用 JavaScript 星期编号：

- `0`：星期日
- `1`–`5`：星期一至星期五
- `6`：星期六

如果只有个别线路例外，请在 `overrides.json` 增加覆盖项：

```json
[
  {
    "direction": "toHengqin",
    "serviceName": "A5线-澳琴午下班",
    "serviceDays": [1, 2, 3, 4, 5],
    "validDates": null
  }
]
```

`validDates` 为 `null` 时不限制日期；也可以填写允许运营的日期数组，例如 `["2026-09-08"]`。

## 生成文件

`src/data/routes.generated.json` 是自动生成文件，请不要直接编辑。提交数据变更时应同时提交该文件，方便代码审查时查看最终数据差异。
